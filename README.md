# IT Support Home Lab

Hands-on projects to develop practical IT support skills using Windows, Linux, virtualization, and troubleshooting tools.

## Objectives

- Practice Windows and Linux administration.
- Learn user account and permission management.
- Diagnose network connectivity and DNS issues.
- Document technical incidents and solutions.
- Develop professional IT support communication skills in English.

## Projects

### 01. Home Lab Setup
**Status:** In progress

Create a virtual lab using Oracle VirtualBox, Windows 11 Enterprise Evaluation, and Ubuntu Desktop.

Skills: Virtualization, operating system installation, system updates, snapshots, and technical documentation.

### 02. Users and Permissions
**Status:** Planned

Create and manage local user accounts, reset passwords, configure groups, and control file and folder permissions in Windows and Linux.

Skills: Account administration, access control, Linux groups, and password management.

### 03. Network Troubleshooting
**Status:** Planned

Investigate simulated connectivity and DNS failures using Windows and Linux networking tools.

Skills: TCP/IP fundamentals, IP configuration, ping, DNS resolution, nslookup, and traceroute.

### 04. Help Desk Ticket Simulation
**Status:** Planned

Document five simulated support tickets, record troubleshooting steps, prioritize incidents, and practice professional communication with users in English.

Skills: Incident documentation, troubleshooting, prioritization, and customer communication.
